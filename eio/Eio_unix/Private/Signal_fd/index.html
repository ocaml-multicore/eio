Module Private.Signal_fd

type t = private Unix.file_descr
val get_singleton : unit -> t

get_singleton () returns a file descriptor that becomes readable when a signal is received (for a Signal_handle handler installed by Eio_unix.set_signal).

Backends should monitor this FD so that they wake up and take the runtime lock when it is readable. This enables the signal to be processed promptly.

The FD is created lazily the first time the function is called and never closed.

val ack : t -> unit

ack t reads one or more pending events from the FD. Call this when t becomes readable.
