Module Eio_unix.Backend_config

Configuration settings to pass to Eio_main.run.

Unknown settings are ignored, so you can pass options for e.g. Eio_linux.run and they will be ignored if Eio_posix is used instead.

type linux = [
  1. | `Uring_queue_depth of int
    (*

    The number of jobs that can be submitted in one batch.

    *)
  2. | `Uring_fixed_buffer of fixed_buffer option
    (*

    Use a fixed buffer to speed things up, if possible. If there isn't enough locked memory available, this is ignored.

    *)
  3. | `Uring_polling_timeout of int option
    (*

    How long (in ms) to continue polling when there's nothing to do. If None, polling isn't used.

    *)
]
